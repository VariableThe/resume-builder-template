# newinfo/ — incoming material for the next resume revision

Drop plain-text notes here as you gain them: new projects, achievements,
skills, certifications, numbers with dates. One file per topic is fine
(e.g. `olivrg-results.md`, `internship-2026.md`).

Keep each note factual and measurable:

- What was built / done, with stack and dates.
- Scale, users, latency, accuracy, or other numbers when known.
- Links to repos or demos only if they are presentable.

`scripts/build.py` does not read this folder; it is source material for
step 2 of `rule.md`. Promote vetted bullets into `master_achievements.md`
(private, gitignored) and then into the working resume.
